06 / FAQ

Answers before you connect.

What is SIGMA XMD?
SIGMA XMD is a WhatsApp bot platform. This portal is the authentication surface used to connect an authorized WhatsApp account to the running bot.
How do I generate a pairing code?
Enter your full international phone number using digits only, then select Generate Pairing Code. The backend must be ready before it can return a code.
How do I scan the QR code?
Open WhatsApp, go to Settings, select Linked Devices, choose Link a Device, and scan the live QR displayed in the QR authentication section.
Why did my pairing code expire?
WhatsApp pairing codes are temporary. Request a fresh code from this page and enter it promptly in the Linked Devices flow.
Why is the QR code not working?
The QR may have expired or the bot may still be connecting. Use Refresh QR, keep the page open, and scan the newest image shown by the backend.
Is my phone number stored?
The browser sends the number to the existing `/api/pair` endpoint for the pairing request. This frontend does not persist it in local storage or cookies.
What should I do if authentication fails?
Confirm the number format, wait for the service to become ready, then retry. If the backend reports a rate limit or connection error, wait before making another request.
